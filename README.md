A simple and fun Rock Paper Scissors game built using Python.
In this game, the user plays against the computer. The computer randomly selects Rock, Paper, or Scissors, and the winner is decided based on the game rules.

Features
User vs Computer Gameplay
Random Computer Choice
Score Calculation
Beginner-Friendly Python Project
Easy to Run and Understand
Command Line Interface (CLI)
Game Rules
Rock beats Scissors
Scissors beats Paper
Paper beats Rock
Same choices result in a Draw
Technologies Used
Python 3
Random Module
